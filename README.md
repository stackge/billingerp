## 🚀 ინსტალაცია და დაყენება

### საჭირო მოთხოვნები
```
PHP 7.4 ან უფრო ახალი
MySQL 5.7 ან MariaDB 10.2+
Apache/Nginx ვებ სერვერი
Composer (PHP dependency manager)
```

### 1. პროექტის ჩამოტვირთვა
```bash
git clone https://github.com/stackge/billingerp.git
cd billingerp
```

### 2. Composer-ის დამატება
```bash
composer install
```

### 3. ბაზის კონფიგურაცია
```bash
# admin/config.php ფაილში შეაყვანეთ თქვენი ბაზის მონაცემები
cp admin/config.example.php admin/config.php
```

### 4. ბაზის მიგრაციები
```bash
php admin/run_migrations.php
```

### 5. ვებ სერვერის კონფიგურაცია
```apache
# Apache .htaccess მაგალითი
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule ^(.*)$ index.php [QSA,L]
```
